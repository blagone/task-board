# Flowboard

Спокойный персональный трекер задач с канбан-доской, календарём и аналитикой.

**Live:** [flowboard-blagone.vercel.app](https://flowboard-blagone.vercel.app)

## Возможности

- канбан-доска с drag-and-drop и изменением порядка задач;
- проекты, приоритеты, сроки, прогресс и несколько тегов;
- поиск и фильтры по проектам, тегам и приоритетам;
- динамический календарь на ближайшие семь дней;
- архив завершённых задач с восстановлением;
- отмена удаления;
- экспорт и валидируемый импорт резервной копии JSON;
- светлая и тёмная темы;
- локальное хранение данных без передачи на сервер;
- адаптивный интерфейс и установка как PWA.

## Горячие клавиши

- `N` — создать задачу;
- `/` — перейти к поиску;
- `Escape` — закрыть открытую панель.

## Локальный запуск

```bash
npm install
npm run dev
```

Приложение откроется на [http://localhost:3000](http://localhost:3000).

Проверки перед публикацией:

```bash
npm run lint
npm run build
```

## Стек

Next.js 16, React 19, TypeScript, Tailwind CSS 4, Vercel Analytics.

Данные задач и архива сохраняются в `localStorage` текущего браузера. Для переноса между устройствами используйте экспорт и импорт JSON.
